# CUSTOMER-CHURN-PREDICTION-MODEL

This project predicts whether a customer will **leave the service (churn)** or **continue**, based on customer usage patterns and demographics. Businesses can use this model to retain customers and reduce losses.

---

## 📌 Objective
To build a **Machine Learning model** that classifies customers as:
- **Churn (Leaving)**
- **Non-Churn (Staying)**

---

## 🧠 Machine Learning Approach
### Steps Involved:
1. **Data Cleaning & Preprocessing**
2. **Exploratory Data Analysis (EDA)**
3. **Feature Encoding**
4. **Model Training (Random Forest / Logistic Regression / XGBoost etc.)**
5. **Model Evaluation**
